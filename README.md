# TimeOmni-o1 · MMTR

Anonymous project page for a submission under double-blind review:
**TimeOmni-o1: Multimodal Time Series Reasoning by Coupling a Time Series Foundation Model with a Large Language Model**.

The page (`index.html`) collects, from the submitted manuscript and its appendix:

- the abstract;
- the model figures (overview and the two coupling pathways) with the corresponding method text;
- the MMTR dataset: comparison with related corpora, composition of the understanding task, provenance of the forecasting task, and the annotation protocol;
- 17 annotated samples (one per understanding discipline, one per forecasting domain);
- six case studies with the full reasoning traces generated by the model and the raw outputs of the compared models.

The site is static: open `index.html` directly, or view it through GitHub Pages
(the workflow in `.github/workflows/pages.yml` deploys the repository root on every push to `main`).
